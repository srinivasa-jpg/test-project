WEATHER REPORT PROJECT

Files:
- index.html
- style.css
- script.js

SETUP:
1. Create a free OpenWeather account.
2. Copy your API key.
3. Open script.js.
4. Replace:
   YOUR_API_KEY_HERE
   with your actual API key.
5. Open index.html in a browser.

For best results, run the project with the Live Server extension in VS Code.
